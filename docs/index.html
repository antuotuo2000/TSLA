Tesla（TSLA）价值投资分析

Tesla

TSLA

NASDAQ · 汽车 / 能源 / 自动驾驶 / AI机器人

我先给出一个核心判断：

Tesla 是一家拥有优秀品牌、技术积累和巨大长期想象空间的公司，但它并不是一只可以简单用传统汽车公司 PE 来估值的股票。

Tesla 最大的问题不是有没有增长空间，而是：

  • 汽车业务未来还能不能维持较高利润率？
  • FSD（完全自动驾驶）能否真正商业化？
  • Robotaxi 能否形成规模化、可持续的收入？
  • Optimus 人形机器人能否从研发项目变成高利润业务？
  • 当前股价是否已经提前计入了这些未来的成功？

从价值投资角度，我会把 Tesla 拆成汽车、能源、自动驾驶和机器人四部分，分别估值，而不是直接相信公司的长期愿景。

一、先看公司的商业模式：Tesla究竟靠什么赚钱？

Tesla 已经不只是一家汽车公司，但目前汽车依然是其收入和利润的核心。

1. 电动汽车

(当前核心业务)

Model 3、Model Y、Model S、Model X、Cybertruck 等，靠车辆销售、租赁和相关服务赚钱。

2. 储能业务

Megapack、Powerwall、电网储能系统。

通过销售储能设备和相关服务赚钱。

3. 自动驾驶与软件

FSD、Robotaxi。

未来可能通过订阅费、自动驾驶出行服务获得持续收入。

4. 人形机器人

Optimus。

目前属于长期研发与商业化探索，未来可能进入工业生产和服务领域。

我的判断：

Tesla 真正值得关注的长期资产，不仅是汽车制造能力，而是汽车、能源、软件、自动驾驶和机器人之间可能形成的协同效应。

但必须区分：汽车和储能是已经存在的商业业务，Robotaxi 和 Optimus 的长期利润则不能提前当成已经实现的利润。

四、未来增长空间：四个业务分别分析

1. 汽车：成熟业务，增长仍有空间

优点：

  • Model 3、Model Y拥有较强品牌基础。
  • 规模化制造可以降低成本。
  • 未来低价车型可能扩大市场。

风险：

  • 全球电动车竞争越来越激烈。
  • 汽车产品更新周期可能影响销量。
  • 价格战会直接侵蚀利润。

我认为汽车业务未来仍会是Tesla的现金流基础，但不能简单假设汽车销量增长就意味着利润同步增长。

2. 储能：我认为这是最值得重视的业务之一

为什么我看好储能？

AI数据中心、电网升级、可再生能源的发展，都需要大量储能设备。

Tesla的Megapack具备一定优势：

  • 大规模储能产品。
  • 软件和能源管理能力。
  • 全球销售和部署网络。

不过，2026 Q3储能收入为28.81亿美元，同比下降16%，不能只凭长期行业前景就认定当前增长没有问题。

我会持续关注储能部署量、订单积压、毛利率和产能利用率。

3. FSD和Robotaxi：可能改变Tesla估值的业务

这是Tesla最重要的估值变量之一。

假设未来Robotaxi真的实现规模化：

  • Tesla可以从卖汽车转向提供出行服务。
  • 每辆车可能持续创造服务收入。
  • 软件和自动驾驶服务可能带来更高利润率。

但有几个问题：

  • 能否真正实现无安全员运营？
  • 事故责任如何划分？
  • 各国监管是否允许？
  • 单位里程成本是否低于传统网约车？
  • 能否形成足够高的车辆利用率？

截至2026 Q3，Tesla已经在Austin使用Cybercab开展Robotaxi服务，但仍处于商业化早期。FSD订阅用户达到174万，同比增长67%，这是值得关注的进展。

4. Optimus：高风险、高想象空间

如果未来人形机器人可以承担工业生产、搬运、装配等任务，市场空间确实很大。

但我不会现在就给Optimus太高的估值。

原因很简单：

机器人能够演示动作，不代表能够在真实工厂里连续工作、低成本维护并创造正向投资回报。

我的处理方式是：在基础估值中给予很低的价值，等出现量产、真实订单和可验证利润后再提高估值。

最大的问题是关键人物风险。

Tesla的品牌、战略方向和市场预期，都与Musk有很强的关联。

另外，2026年10月，Tesla与SpaceX潜在合并的讨论引发了市场关注。这类交易如果发生，必须仔细评估资产估值、交易结构、利益冲突和股东稀释问题。

我的观点：

Musk是Tesla最重要的竞争优势之一，也可能是Tesla最大的治理风险之一。

1. 为什么传统PE估值不够用？

如果Tesla只是汽车公司，400多倍PE显然很难成立。

但市场实际上给它定价的是：

  • 汽车制造商。
  • 储能科技公司。
  • 自动驾驶软件公司。
  • Robotaxi平台。
  • 人形机器人公司。

问题是：这些未来业务究竟能创造多少利润？

因此我采用分部估值（SOTP）和未来正常化利润估值相结合的方法。

2. 三种估值情景

如果Robotaxi和机器人业务没有兑现，传统汽车和储能业务很难单独支撑现在的市值。

八、我的买入价格和建仓策略

如果按照传统价值投资方式，我不会因为看好Musk、Robotaxi或者Optimus，就在当前价格追高。

什么情况下应该卖出？

我不会只用股价跌幅决定卖出，而会关注投资逻辑是否被破坏。

  • 汽车业务长期无法恢复合理利润率。
  • FSD持续无法实现规模化商业变现。
  • 储能业务竞争恶化，利润率持续下降。
  • 管理层出现严重损害普通股东利益的资本配置行为。
  • 股价远远超过合理价值，未来预期回报明显下降。

十、我想特别提醒你的一件事

你之前分析过NVDA、GOOGL、NFLX、RKLB、ONON等公司，我认为Tesla和这些公司有一个很大的区别：

Tesla的股价对未来预期的依赖程度非常高。

我会把它和两类公司区别开：

  • GOOGL：已经拥有成熟、强大的现金流业务。
  • Tesla：目前汽车和能源业务提供基础，但更高估值需要自动驾驶、机器人等业务兑现。

如果从巴菲特式价值投资角度出发，我宁愿以合理价格买入一家已经能够稳定产生大量自由现金流的企业，也不愿意为了尚未兑现的机器人利润支付过高溢价。

我的建议

Tesla可以放入长期观察名单，但我不会把它作为当前价值投资组合的核心仓位。

我更想进一步帮你回答一个问题：

Tesla、BYD、Toyota、GM，究竟哪家公司未来5年最有可能为股东创造最高的自由现金流回报？

这个比较比单独研究Tesla更有投资价值。
